# HUA website baseline

A local, responsive baseline recreation of the public homepage at [thehua.org](https://www.thehua.org/). It uses plain HTML, CSS, and JavaScript so the visual system can be changed quickly during the Figma design phase.

## Run locally

```bash
npm run dev
```

Then open <http://localhost:4173>.

The original homepage imagery is stored locally in `assets`; no Squarespace runtime is required.
